# Public course catalogue showcase block

`block_catalogo_publico` embeds the public discovery surface supplied by
`local_catalogo_publico`. It contains no course queries, filters, templates,
or theme-specific styling rules of its own.

Install `local_catalogo_publico` first, then add this block to the site home
page's catalogue region.

For a scripted installation on the front page, run
`php cli/add_to_frontpage.php` from this plugin directory as a Moodle site
administrator.
